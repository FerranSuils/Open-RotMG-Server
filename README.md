Rust backend for the Open RotMG recreation of Realm of the Mad God.

## Run locally

Install Rust/Cargo and Python 3. Clone https://github.com/OpenRotMG/Open-RotMG-Client beside this repository as `client`.

```sh
./run.sh
```

Open http://127.0.0.1:18923/ to play the development game.
