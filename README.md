<h1><img src=".github/readme-icon.png" width="44" height="44" align="absmiddle" alt=""> Open RotMG / Server</h1>

Rust backend for the recovered **123.5.1** client: Wizard Tutorial, Nexus, generated Realm terrain, shore combat, earned Pirate Cave entry, world-local chat, trading, guest-to-registered accounts and a private eight-slot account Vault. Native Legends ranks permanent-death records. World actors and SQLite handle combat, progression and permanent death. `data/README.md` documents the provisional map and encounter candidates.

## Run locally

Install Rust/Cargo and Python 3, then run. The client downloads automatically:

```sh
./run.sh 8080
```

Open the URL printed when the server is ready.
