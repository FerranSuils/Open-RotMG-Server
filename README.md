Rust backend for the Open RotMG recreation of Realm of the Mad God.

## Run locally

Install Rust/Cargo and Python 3, then run. The client downloads automatically:

```sh
./run.sh
```

Optionally pass a port (default: `18923`):

```sh
./run.sh 8080
```

Open the URL printed when the server is ready.
